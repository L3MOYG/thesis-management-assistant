# Registro de decisiones

> Bitácora del proyecto. Sustituye a la memoria del Project cuando está desactivada y la respalda cuando está activa. Solo se añade: una decisión revocada no se borra, se marca como sustituida por la que la reemplaza.

## Decisiones

Cada decisión es del autor. El asistente propone, argumenta y registra.

| ID | Fecha | Fase | Decisión | Alternativas consideradas | Fundamento | Archivos afectados | Estado |
|---|---|---|---|---|---|---|---|
| D-001 | | | | | | | vigente |

Convenciones de la columna Fundamento: escribe **hecho** cuando se apoya en una fuente o en un cálculo que puede reproducirse, **inferencia** cuando es una deducción a partir de hechos, y **preferencia** cuando es una elección del autor sin obligación técnica.
